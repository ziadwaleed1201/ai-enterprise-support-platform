# SupportAI Requirements

## User Roles

### Employee
- Log in
- Create support tickets
- Add attachments
- View ticket status
- Add comments
- View ticket history
- Use the AI knowledge assistant

### Support Agent
- View assigned tickets
- Update ticket status
- Change priority
- Add comments
- Resolve tickets
- Use AI-generated response suggestions

### Admin
- Manage users
- Manage departments
- Manage ticket categories
- Manage support agents
- Configure SLA rules
- Manage company knowledge documents
- View system analytics
