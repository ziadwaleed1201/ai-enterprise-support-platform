# SupportAI — Enterprise Support Management Platform

SupportAI is an AI-powered enterprise support platform for managing employee requests across departments such as IT, HR, Finance, and Administration.

The platform combines traditional ticket management with AI features such as ticket classification, priority suggestions, response generation, summarization, and a RAG-based company knowledge assistant.

## Planned Tech Stack

- Frontend: Next.js + TypeScript
- Backend: Java + Spring Boot
- AI Service: Python + FastAPI
- Database: PostgreSQL
- Vector Search: pgvector
- Authentication: Spring Security + JWT
- API Documentation: Swagger / OpenAPI
- DevOps: Docker + GitHub Actions

## Main User Roles

- Employee
- Support Agent
- Admin

## Core Features

- Authentication and role-based access
- Ticket creation and tracking
- Department and category management
- Ticket assignment
- Comments and attachments
- Ticket history
- SLA tracking
- Notifications
- Dashboards and analytics

## AI Features

- Automatic department classification
- Category suggestion
- Priority recommendation
- Ticket summarization
- Suggested support responses
- RAG-based company knowledge assistant
- Source-based answers from uploaded company documents
